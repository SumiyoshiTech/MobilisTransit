    1. Generates a pilot multi-scenario dataset (`ml.dataset_gen`), creates & audits leak-free splits (`ml.splits`), trains & exports a versioned AAP model (`ml.train`), and runs held-out evaluation (`ml.evaluate`) verifying zero leakage and complete metrics (`EVAL-001`, `BR-012`).

    3. Verifies SSE live push (`GET /journeys/{id}/stream`) receives a snapshot within `< 1 s` of playback step (`DEC-003`, `CON-006`) and playback pause/restart invariants (`BR-003`, `BR-009`).
    4. Runs a real paired delay experiment via `POST /experiments` (`stop_hold_s=180` at `P02` + `traffic_multiplier=1.2`), confirms deduplication on duplicate submit (`BR-008`), waits for `COMPLETED`, and verifies stop-by-stop observed arrival differences (`BR-005`, `BR-006`).
    5. Verifies `/admin` HTML/JS assets load cleanly (`REQ-014`) and runs the 5-category LangGraph agent audit (`evaluation.agent_eval`) against the real DB records created in step 4 (`REQ-015`, `BR-013`, `EVAL-003`).
    6. Submits realistic telemetry events to `POST /telemetry/events` and executes `evaluation.latency_analysis` verifying `< 2 s` live-demo target computation (`REQ-016`, `EVAL-004`).
