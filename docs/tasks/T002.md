# T002: Deterministic SUMO/TraCI simulation worker, replay engine & unified source adapter
- **State**: `approved`
- **Dependencies**: `T001`
- **Allowed files**: `backend/app/simulation/traci_runner.py`, `backend/app/simulation/replay.py`, `backend/app/adapter/__init__.py`, `backend/app/adapter/source_adapter.py`, `backend/tests/test_simulation_and_adapter.py`

## Objective
Implement the deterministic Python/TraCI simulation runner supporting stop holds (`setStop`) and background traffic multipliers (`REQ-001`, `BR-005`, `BR-007`, `CON-002`), a recorded-journey replay stream controller with Play/Pause/Step/Restart (`REQ-002`, `BR-003`), and the unified `SourceAdapter` converting both live SUMO and recorded replay outputs into one canonical state format (`REQ-002`).

## Contracts
- **`backend/app/simulation/traci_runner.py`**:
  - `SimulationRunConfig` (Pydantic model): `network_dir: Path`, `journey_id: str`, `scenario_id: str`, `execution_id: str`, `demand_profile: Literal["off_peak", "campus_rush", "heavy_congestion"]`, `departure_time_s: int`, `random_seed: int`, `intervention_stop_id: str | None = None`, `stop_hold_s: int = 0` (`0 <= stop_hold_s <= 900`), `traffic_multiplier: float = 1.0` (`0.5 <= traffic_multiplier <= 2.5`), `snapshot_interval_s: int = 1`, `timeout_s: int = 180`.
  - `SimulationRunResult`: `config`, `network_version`, `raw_snapshots: list[RawVehicleState]`, `observed_arrivals: list[ObservedStopArrival]`, `completed_cleanly: bool`, `sim_duration_s: int`.
  - `run_sumo_simulation(config: SimulationRunConfig, on_snapshot: Callable[[RawVehicleState], None] | None = None) -> SimulationRunResult`:
    - Launches SUMO headless via TraCI (`--seed <random_seed>`, `--scale <effective_scale>` combining demand profile base factor × `traffic_multiplier`, `--step-length 1.0`).
    - Reads vehicle telemetry via `traci.vehicle.getRoadID`, `getLanePosition`, `getSpeed`, `getDistance`, `getStopState`, and `getNextStops`.
    - When `stop_hold_s > 0` and `intervention_stop_id` is set, applies `traci.vehicle.setStop` (or extends scheduled stop duration by `stop_hold_s` seconds on the mapped `sumo_bus_stop_id`) once the bus is active in SUMO.
    - Tracks exact actual arrival timestamp (`simulation_clock_s`) and dwell duration when the bus arrives at and departs each ordered stop, plus `last_completed_stop_dwell_s` and `ongoing_stop_elapsed_s` strictly causally!
    - Always closes TraCI cleanly in a `finally:` block even on exceptions or timeouts.
- **`backend/app/simulation/replay.py`**:
  - `RecordedJourneyPlayer`: initialized with a list of recorded `CanonicalVehicleState` snapshots; manages `execution_id`, `sequence_number` (resets to `1` with new `execution_id` on `restart()`), `playback_state` (`PLAYING` | `PAUSED` | `STOPPED`), `play()`, `pause()`, `step()`, `restart()`, and `current_state()`.
- **`backend/app/adapter/source_adapter.py`**:
  - `CanonicalVehicleState` (Pydantic model): `source` (`SIMULATION` | `RECORDED_REPLAY`), `journey_id`, `route_id`, `scenario_id`, `execution_id`, `sequence_number`, `simulation_clock_s`, `playback_state`, `worker_generated_at_ms`, `vehicle_id`, `status`, `edge_id`, `lane_position_m`, `distance_travelled_m`, `speed_mps`, `current_segment_index`, `last_visited_stop_id`, `next_stop_id`, `ongoing_stop_elapsed_s`, `last_completed_stop_dwell_s`, `demand_profile`.
  - `SourceAdapter` protocol + `SumoSourceAdapter` and `ReplaySourceAdapter` producing identical `CanonicalVehicleState` objects (and stub interface comment for future GPS telemetry per `REQ-002`, keeping live GPS ingestion out of scope).

## Implementation steps
1. Implement `RawVehicleState`, `ObservedStopArrival`, `SimulationRunConfig`, and `run_sumo_simulation` in `backend/app/simulation/traci_runner.py` using `resolve_sumo_binary()` and `load_and_validate_manifest()` from `T001`. Support both the 4-stop fixture (`sumo/fixtures/sample_line9/`) and the real 22-stop circular Line 9 network (`sumo/`, where routes/vehicles live in `additional_files`, `.net.xml.gz` is compressed, and `gtfs_lra_0096` repeats at `sequence_index` `0` and `21`).
2. Scale ONLY background traffic (NEVER pass global `--scale` to SUMO, which would duplicate/drop Line 9 buses — use seeded background-traffic XML scaling into a temporary run-scoped file, scaled by demand-profile base factor × `config.traffic_multiplier`).
3. Run SUMO at `--step-length 1.0` (1 s resolution required for `EVAL-001`'s `1 s`/`5 s`/`30 s` intervals and exact 10 s stop detection). Track stop arrivals by **ordered `sequence_index` / `stop_id`** (not by raw `sumo_bus_stop_id` set) so circular Line 9 records BOTH origin (`P01`) and return-to-terminal (`P22`) arrivals for `gtfs_lra_0096`. Record exact `observed_arrival_s`, increment `ongoing_stop_elapsed_s` each 1 s step while stopped, and latch `last_completed_stop_dwell_s` upon departure.
4. Implement `SourceAdapter` (`SumoSourceAdapter`, `ReplaySourceAdapter`) in `backend/app/adapter/source_adapter.py` (clean production implementation under `backend/` carrying `execution_id`, `sequence_number`, causal dwell fields, and `worker_generated_at_ms`; ignore archived prototypes in `sumo/deprecated/`).
5. Implement `RecordedJourneyPlayer` in `backend/app/simulation/replay.py`.
6. Write `backend/tests/test_simulation_and_adapter.py` covering determinism, stop-hold downstream delay propagation, traffic-multiplier execution, adapter schema parity, and replay play/pause/restart sequence semantics.

## Edge cases and security
- Use unique TraCI connection labels (`f"mt_{uuid4().hex[:12]}"`) and free TCP ports (`traci.start(..., label=label)`) so concurrent or sequential tests never collide on default port `8813`.
- Guarantee `traci.switch(label); traci.close()` in `finally:` so zombie `sumo.exe` processes are never left running on Windows.
- Validate `stop_hold_s` ∈ `[0, 900]`, `traffic_multiplier` ∈ `[0.5, 2.5]`, and `intervention_stop_id` exists in manifest BEFORE spawning SUMO (`BR-007`).
- Guard against `--scale` dropping the bus itself: verify bus vehicle `manifest.bus_vehicle_id` appears in SUMO; if SUMO's global `--scale` scales flows, either scale only background flow probability in a temporary run-scoped `.rou.xml` copy (recommended! 100% immune to duplicating/dropping the bus) instead of global `--scale`.
