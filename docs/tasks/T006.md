## Objective
Implement the AAP regression models (Historical Segment-and-Stop Average Baseline, Static Published Timetable Comparator, Regularized Linear Regression `Ridge`, and `XGBoost`), build the primary **Google Colab training & evaluation notebook** (`MobilisTransit_AAP_Training_Colab.ipynb`) backed by reusable pure-Python `ml/` modules, export **cross-Python/cross-OS portable JSON model bundles** (zero `pickle`/`joblib` fragility between Linux Colab and Windows Python 3.13), and integrate artifact loading into the central backend `PredictionService` (`REQ-004`, `REQ-005`, `BR-012`, `BR-014`, `EVAL-001`).

## Contracts
- **`ml/baselines.py`** *(pure Python + numpy/pandas)*:
  - `HistoricalSegmentAverageModel`: learns mean segment travel duration and mean stop dwell duration per `(demand_profile, segment_index)` strictly on `train` split, predicts remaining time by summing the proportional remaining part of the current segment plus downstream mean segment and dwell durations (falling back to global segment means for unseen demand profiles), and serializes cleanly via `to_dict()` / `from_dict()`.
  - `StaticTimetableComparator`: computes `reference_timetable_s - simulation_clock_s` for rows where reference timetable exists (marking missing rows as unavailable, `BR-001`).
- **`ml/serialization.py` (PORTABLE JSON ARTIFACT FORMAT — ZERO `pickle`/`joblib`!)**:
  - Guarantees models trained in **Google Colab** (Linux, Python 3.11/3.12) load deterministically on the **Windows host server** (Python 3.13) with zero version-mismatch crashes or pickle security risks:
    - `PortablePreprocessor`: fits numeric imputation medians, `StandardScaler` means/stds, and `demand_profile` one-hot vocabulary strictly on `train`, and serializes to `preprocessor.json` (`to_dict()` / `from_dict()`).
    - `save_portable_model_bundle(bundle_dir, model_type, model_obj, preprocessor, metadata)` & `load_portable_model_bundle(bundle_dir) -> LoadedModelBundle`:
      - `xgboost`: saves via native `XGBRegressor.save_model("model_xgb.json")` and loads via `XGBRegressor.load_model(...)`.
      - `ridge`: saves `{"coef": [...], "intercept": float, "alpha": float}` in `model_ridge.json` (pure dot-product inference in `numpy`!).
      - `historical_baseline`: saves `model_historical.json` via `HistoricalSegmentAverageModel.to_dict()`.
      - Always writes `metadata.json` (`model_version`, `model_type`, `feature_columns`, `trained_at`, `training_environment` [e.g. `google_colab` / `local`], `python_version`, `xgboost_version`, `val_metrics`, `dataset_hash`, `simulation_domain_notice` per `BR-014`) and `preprocessor.json`.
- **`ml/train.py`** *(supports both `--dataset-bundle <colab_zip_or_dir>` and `--db <database_url>`)*:
  - Enforces `audit_splits()` (`BR-012`), fits `HistoricalSegmentAverageModel` on `train`, fits & tunes `Ridge` (`alpha` grid on `val`) and `XGBRegressor` (depth/learning_rate/n_estimators on `val`, auto-selecting `device="cuda"` if GPU available in Colab else `"cpu"`) strictly on `train`/`val` (NEVER touching `test` during selection!).
  - Selects winning model by lowest `val` per-journey MAE across normal + delayed trips, exports portable JSON bundle to `ml/artifacts/<model_version>/`, updates `ml/artifacts/active_model.json`, and optionally writes `<model_version>_artifact.zip` for 1-click download from Colab.
- **`ml/evaluate.py`** *(supports both `--dataset-bundle` and `--db`)*:
  - Evaluates all models (`historical_baseline`, `static_timetable`, `ridge`, `xgboost`) on the locked `test` split.
  - Computes `MAE`, `RMSE`, and `P90` absolute error:
    1. **Per-journey** (mean & median across test journeys) and **pooled** across observations
    2. By **stop_id**, **prediction horizon bucket** (`0-120s`, `120-300s`, `300s+`), **demand_profile**, and **normal vs. disrupted** (before/during/after hold)
    3. Across **observation update intervals**: `1 s`, `5 s`, and `30 s` (`EVAL-001`)
  - Emits machine-readable JSON + human-readable Markdown report explicitly stating simulation-domain validity boundaries (`BR-014`) and checking pass criteria (beats historical baseline MAE; compares against provisional `< 60 s` utility target).
- **`ml/notebooks/MobilisTransit_AAP_Training_Colab.ipynb` (PRIMARY GOOGLE COLAB WORKFLOW)**:
  - Clean, self-contained Jupyter/Colab notebook with clear Markdown explanations and runnable cells:
    1. Environment setup (`pip install xgboost scikit-learn pandas numpy matplotlib` + runtime/GPU inspection).
    2. Load code (`ml/` from GitHub/Google Drive or direct upload) and load `colab_dataset_bundle.zip` exported by `T005`.
    3. Verify dataset summary and run `audit_splits()` (`BR-012`).
    4. Run `ml.train` comparing Historical Baseline, Ridge, and XGBoost on `train`/`val` and display validation comparison table.
    5. Run `ml.evaluate` on the locked `test` split across normal/disrupted trips and `1 s / 5 s / 30 s` intervals, plotting MAE comparisons & error distributions.
    6. Package and download the portable JSON artifact bundle (`<model_version>_artifact.zip`) with instructions to extract directly into `ml/artifacts/` on the local server.
- **`backend/app/prediction/service.py`**:
  - Loads `active_model.json` → `load_portable_model_bundle(...)` (JSON + native XGBoost JSON — zero `pickle`/`joblib`), calls `ml.features.build_online_feature_row(...)` using the journey's causal snapshot ring buffer, clips predicted remaining seconds to `>= 0` (rounding to int), tags every `JourneySnapshotDto` with `metadata.model_version`, and returns `prediction_available=False` if inference fails (`BR-002`, `REQ-005`).

## Edge cases and security
- **No unsafe deserialization**: Strictly prohibit `pickle.load` / `joblib.load` in `ml/serialization.py` and `backend/app/prediction/service.py` — load only validated JSON files and native XGBoost JSON models inside `ml/artifacts/` (preventing both cross-Python Colab→Windows crashes and arbitrary-code-execution risks).
- Validate `active_model.json` target path stays strictly inside the configured `ml/artifacts` directory.
- Handle unseen `demand_profile` categories gracefully (`unknown` → all-zero one-hot vector in `PortablePreprocessor`).
- Clamp negative linear predictions with `max(0.0, pred)`.
- Never allow `ml/train.py` to inspect `test` rows during hyperparameter tuning (`BR-012`).
