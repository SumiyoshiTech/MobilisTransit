## Objective
Implement the AAP multi-scenario SUMO dataset generator (producing both historical DB records and a self-contained **Google Colab export bundle**), the strictly causal pure-Python feature engineering module shared identically between Google Colab training and online Windows backend inference, and the family-grouped leakage-free train/validation/test splitter with an automated leakage auditor (`REQ-001`, `REQ-004`, `BR-012`).

> **Review Flag**: Complex / scientific-validity critical task (strict causality and zero train/test data leakage per `BR-012` and `main_changes7.tex` §4.3/§6).

## Contracts
- **`ml/dataset_gen.py`**:
  - CLI & callable `generate_dataset(network_dir: Path, database_url: str, profile: Literal["pilot", "full"] = "pilot", output_dir: Path | None = None) -> DatasetSummary`:
    - Generates paired experiment families across `demand_profile` (`off_peak`, `campus_rush`, `heavy_congestion`), departure offsets, independent random seeds, normal trips (`stop_hold_s=0, traffic_multiplier=1.0`), and disrupted trips (varied stop holds across stops + traffic multipliers).
    - Reserves distinct random seeds AND unseen demand/delay combinations specifically tagged as `held_out_candidate` so the test split genuinely tests generalization (`BR-012`, `main_changes7.tex` §6).
    - Persists every generated journey, snapshot (1 s resolution so `1 s`, `5 s`, and `30 s` intervals can be evaluated cleanly in `T006`), and observed stop arrival into the historical DB (`T003`), AND exports a self-contained **Google Colab dataset bundle** (`output_dir/colab_dataset_bundle.zip` containing `journeys.csv`, `snapshots.csv`, `arrivals.csv`, `stops.json`, `split_manifest.json`, and `dataset_metadata.json` — pure CSV/JSON so Colab needs zero extra Parquet/SQLite setup!).
    - `pilot` profile runs fast (`~18` journeys / `~6` families, completing in `< 30 s` on `sample_line9`); `full` profile scales to configurable matrix (e.g., `60+` journeys) for final Line 9 Google Colab training.
- **`ml/features.py`** *(PURE PYTHON — ZERO SUMO/FASTAPI/SQLALCHEMY IMPORTS — SHARED BY GOOGLE COLAB AND BACKEND)*:
  - `CAUSAL_FEATURE_COLUMNS: list[str]` — exact ordered list matching [docs/ARCHITECTURE.md](../ARCHITECTURE.md) §4.6:
    `["distance_travelled_m", "remaining_distance_m", "current_segment_index", "target_stop_index", "remaining_stops_count", "current_speed_mps", "recent_avg_speed_30s_mps", "recent_avg_speed_60s_mps", "last_completed_stop_dwell_s", "ongoing_stop_elapsed_s", "time_of_day_sin", "time_of_day_cos", "demand_profile"]`.
  - `build_online_feature_row(snapshot_history: Sequence[CanonicalVehicleState], current_state: CanonicalVehicleState, stops: Sequence[StopManifest], target_stop: StopManifest) -> dict[str, Any]`: computes one strictly causal feature dict using ONLY snapshots with `simulation_clock_s <= current_state.simulation_clock_s`.
  - `build_supervised_dataset(journeys_df, snapshots_df, arrivals_df, stops_df, observation_interval_s: int = 1) -> pd.DataFrame`: expands completed journeys into `(r, s, t)` supervised rows for all downstream stops where `t < a_{r,s}`, computing `target_remaining_s = observed_arrival_s - simulation_clock_s` and invoking the EXACT same rolling speed & feature logic as `build_online_feature_row` (guaranteeing train/serve parity!). Also attaches metadata columns (`journey_id`, `experiment_family_id`, `random_seed`, `stop_id`, `simulation_clock_s`, `is_disrupted`, `demand_profile`, `stop_hold_s`, `traffic_multiplier`) strictly outside `CAUSAL_FEATURE_COLUMNS`.
- **`ml/splits.py`**:
  - `create_leak_free_splits(journeys_df: pd.DataFrame, manifest_path: Path, train_ratio=0.6, val_ratio=0.2, test_ratio=0.2) -> SplitManifest`:
    - Groups complete journeys by `experiment_family_id` AND enforces zero `random_seed` overlap between `test` and `train`/`val`.
    - Ensures `test` contains both normal and disrupted journeys, including unseen delay durations / traffic multipliers where present.
    - Writes locked `manifest_path` (`split_manifest.json`) listing exact `train_journey_ids`, `val_journey_ids`, `test_journey_ids`, `test_seeds`, and dataset hash.
  - `audit_splits(supervised_df: pd.DataFrame, split_manifest: SplitManifest, feature_columns: Sequence[str]) -> SplitAuditReport`:
    - Raises `DataLeakageError` if: (1) any `journey_id`, `experiment_family_id`, or `random_seed` appears in more than one split; (2) any row has `target_remaining_s <= 0` (`t >= a_{r,s}`); (3) any forbidden column (`observed_arrival_s`, `target_remaining_s`, `stop_hold_s`, `traffic_multiplier`, `total_trip_duration`) is in `feature_columns`; (4) rolling speed window reads any timestamp `> t`.

## Implementation steps
1. Implement `ml/features.py` with shared causal rolling-speed computation (`[t-30, t]` and `[t-60, t]`), cyclical time-of-day encoding, online single-row builder, and batch supervised dataset builder supporting subsampling (`observation_interval_s` ∈ `{1, 5, 30}`).
2. Implement `ml/splits.py` with family-and-seed grouped splitting, locked `split_manifest.json` persistence, and `audit_splits()` verifier.
3. Implement `ml/dataset_gen.py` invoking `run_sumo_simulation` (`T002`) and `save_completed_journey` (`T003`) with deterministic scenario matrices (`pilot` and `full` CLI modes via `python -m ml.dataset_gen --profile pilot`).
4. Write `ml/tests/test_features_and_splits.py` verifying strict causality (mutating future snapshots `> t` does NOT change features at time `t`), exact parity between `build_online_feature_row` and `build_supervised_dataset`, zero leakage in `create_leak_free_splits`, negative leakage-detection tests, and pilot dataset generation on `sample_line9`.

## Edge cases and security
- Handle sparse or cold-start speed history at `t = departure_time_s` (when `< 30 s` or `< 60 s` of history exists, average over available causal snapshots `[t_start, t]` instead of returning `NaN`).
- Exclude snapshots after a stop is already reached (`t >= a_{r,s}`) so `target_remaining_s` is strictly positive (`BR-012`).
- Reject overwriting an existing locked `split_manifest.json` unless `--force-resplit` is explicitly passed, protecting the frozen held-out test set (`REQ-004`).
