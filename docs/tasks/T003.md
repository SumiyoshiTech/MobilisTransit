## Objective
Define the application settings, canonical Pydantic v2 REST/JSON contracts enforcing business rules (`BR-001`, `BR-002`, `BR-006`, `BR-007`), and the SQLAlchemy 2.0 relational historical database (SQLite WAL default, PostgreSQL-ready via `DATABASE_URL`) with CRUD, filtering, and ML dataset export repositories (`REQ-003`, `REQ-006`, `CON-003`).

## Contracts
- **`backend/app/settings.py`**: `Settings(BaseSettings)` reading env vars / optional `.env`: `database_url` (default `sqlite:///./data/mobilistransit.db`), `sumo_network_dir` (optional override), `active_model_pointer` (default `ml/artifacts/active_model.json`), `stop_hold_min_s=0`, `stop_hold_max_s=900`, `traffic_multiplier_min=0.5`, `traffic_multiplier_max=2.5`, `max_concurrent_sumo_jobs=1`, `llm_provider="ollama"`, `llm_model="qwen2.5:3b"`, `ollama_base_url="http://localhost:11434"`, `openai_api_base=None`, `openai_api_key=None`.
- **`backend/app/schemas/contracts.py`**:
  - `RouteDto`, `RouteStopDto`, `JourneySummaryDto`, `VehicleStateDto`, `StopPredictionDto`, `JourneySnapshotDto`, `PlaybackControlRequest`.
  - `ExperimentCreateRequest`, `ExperimentJobCreatedDto`, `ExperimentInvariantDto`, `ObservedStopComparisonRowDto`, `ExperimentDetailDto`, `ExperimentComparisonDto`.
  - `TelemetryEventIn`, `TelemetrySummaryDto`, `ErrorEnvelope`.
  - **Enforced Pydantic model validators**:
    - `StopPredictionDto`: if `prediction_available` is `False`, require `remaining_time_s`, `predicted_arrival_s`, `predicted_arrival_iso`, and `predicted_delay_s` to all be `None` (`BR-002`). If `reference_timetable_s` is `None`, require `predicted_delay_s` to be `None` (`BR-001`). Otherwise require `predicted_delay_s == predicted_arrival_s - reference_timetable_s` (`BR-001`).
    - `ExperimentCreateRequest`: `name` stripped non-empty (`<= 120` chars), `stop_hold_s` integer in `[0, 900]`, `traffic_multiplier` float in `[0.5, 2.5]`, `intervention_stop_id` required whenever `stop_hold_s > 0`, and rejects zero-intervention requests unless `allow_zero_intervention=True` (`BR-007`).
- **`backend/app/db/models.py`**: SQLAlchemy 2.0 ORM tables matching [docs/ARCHITECTURE.md](../ARCHITECTURE.md) §4.4: `RouteModel`, `StopModel`, `JourneyModel`, `VehicleSnapshotModel`, `ObservedStopArrivalModel`, `ExperimentJobModel`, `ExperimentRunModel`, `TelemetryEventModel`.
- **`backend/app/db/repositories.py`**:
  - `seed_route_from_manifest(session, manifest)`: idempotently upserts route and ordered stops from `NetworkManifest`.
  - `save_completed_journey(session, run_result, route_id, source, experiment_family_id)`: atomically persists `JourneyModel`, all `VehicleSnapshotModel` rows, and all `ObservedStopArrivalModel` rows.
  - `create_experiment_job(...)` with `idempotency_hash` lookup for active (`QUEUED`/`RUNNING`) jobs and sequential human-readable experiment IDs (`EXP-001`, `EXP-002`, …).
  - `list_experiments(session, route_id=None, demand_profile=None, min_hold_s=None, max_hold_s=None, min_traffic_multiplier=None, max_traffic_multiplier=None, status=None, from_time=None, to_time=None)`.
  - `compare_experiment_runs(session, baseline_exp_id, perturbed_exp_id) -> ExperimentComparisonDto`: computes stop-by-stop observed arrival differences strictly from `observed_stop_arrivals` (`BR-006`).
  - `export_journeys_for_ml(session, route_id=None) -> tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame]`: cleanly exports `(journeys_df, snapshots_df, arrivals_df)` for `ml/` (`REQ-003`).
  - `save_telemetry_events(session, events)` & `summarize_telemetry(session)`.

## Implementation steps
1. Implement `backend/app/settings.py` with `pydantic_settings.BaseSettings` and safe defaults (creating parent `data/` directory automatically for SQLite paths).
2. Implement all canonical DTOs and business-rule validators in `backend/app/schemas/contracts.py`.
3. Implement SQLAlchemy 2.0 `Base`, engine/session factory (`backend/app/db/session.py`) enabling SQLite `PRAGMA journal_mode=WAL` and `PRAGMA foreign_keys=ON` automatically when URL starts with `sqlite:`.
4. Implement all 8 ORM tables in `backend/app/db/models.py` with proper indexes on `(journey_id, sequence_number)`, `(journey_id, stop_id)`, `experiment_id`, and `idempotency_hash`.
5. Implement `backend/app/db/repositories.py` covering seeding, journey persistence, experiment job/run lifecycle, filtering, observed comparison, ML DataFrame export, and telemetry persistence/summary.
6. Write `backend/tests/test_db_and_schemas.py` testing every validator (`BR-001`, `BR-002`, `BR-007`), SQLite restart persistence (`REQ-003`), experiment ID generation (`EXP-001`/`EXP-002`), filtering, observed comparison (`BR-006`), and ML export.

## Edge cases and security
- Ensure `EXP-xxx` sequential ID generation is safe under concurrent transactions (derive from auto-increment integer PK or locked counter row, never racy `COUNT(*) + 1`).
- Never store user GPS/location columns or camera frame blobs in any table (`CON-008`).
- Parameterize all SQL queries through SQLAlchemy ORM/Core expressions — zero string-concatenated SQL.
