## Objective
Build the central FastAPI REST/JSON and SSE server exposing routes, ordered stops, live/replayed journey snapshots with server-side versioned predictions, paired SUMO experiment execution with duplicate-job prevention, clock synchronization, and latency telemetry (`REQ-005`, `REQ-006`, `REQ-016`, `BR-005`–`BR-009`, `CON-003`, `CON-006`, `DEC-002`, `DEC-003`).

> **Review Flag**: Complex / concurrency-sensitive task (async SSE pub-sub, bounded SUMO worker thread pool, idempotent duplicate-job guard, strict validation).

## Contracts
- **FastAPI app factory (`backend/app/main.py`)**: `create_app(settings: Settings | None = None) -> FastAPI`:
  - Lifespan initializes DB tables, loads active SUMO network manifest (seeding `routes` and `stops` into DB), seeds one ready recorded replay journey (`J-DEMO-001`) by running or loading a baseline fixture trip if DB has no journeys yet, loads `PredictionService`, and starts `ExperimentJobManager`.
  - Global exception handlers convert validation/domain errors into `ErrorEnvelope` (`{ error_code, message, details }`).
- **Endpoints** (matching [docs/ARCHITECTURE.md](../ARCHITECTURE.md) §4.2 exactly):
  - `GET /health`, `GET /time`
  - `GET /routes`, `GET /routes/{route_id}/stops`
  - `GET /journeys`, `GET /journeys/{journey_id}/snapshot`, `GET /journeys/{journey_id}/stream` (SSE `text/event-stream`, emits `event: snapshot\ndata: <JSON>\n\n` immediately on snapshot publish + `: keepalive\n\n` heartbeat), `POST /journeys/{journey_id}/playback` (`play`, `pause`, `step`, `restart`)
  - `POST /experiments` (`202 Accepted`, or `200 OK` with `deduplicated=true` when an identical `QUEUED`/`RUNNING` job exists), `GET /experiments`, `GET /experiments/{id}` (resolves either `job_id` or `EXP-xxx`), `GET /experiments/compare?baseline_id=...&perturbed_id=...`
  - `POST /telemetry/events`, `GET /telemetry/summary`
- **`backend/app/prediction/service.py`**:
  - `PredictionService`: loads versioned artifact from `settings.active_model_pointer` if present (populated in `T006`); if no trained artifact exists yet, loads a clean built-in `heuristic-baseline-v0.1.0` fallback predictor computing segment-proportional remaining times so M1 vertical slice works end-to-end and tags every snapshot with `model_version`.
  - Computes `StopPredictionDto` list for all route stops, honoring `BR-001` (omit `predicted_delay_s` when `reference_timetable_s` is `None`) and `BR-002` (return `prediction_available=False` with `None` times if prediction fails or is unavailable).
- **`backend/app/jobs/experiment_manager.py`**:
  - Bounded `ThreadPoolExecutor(max_workers=settings.max_concurrent_sumo_jobs)` executing paired SUMO runs (`BR-005`: identical `network_version`, `demand_profile`, `departure_time_s`, `random_seed`; `EXP-001` baseline has `stop_hold_s=0, traffic_multiplier=1.0`, `EXP-002` perturbed applies requested intervention).
  - Canonical `idempotency_hash` over `(route_id, demand_profile, departure_time_s, random_seed, intervention_stop_id, stop_hold_s, round(traffic_multiplier, 3))` blocks duplicate concurrent jobs (`BR-008`).
  - Updates job lifecycle `QUEUED` → `RUNNING` → `COMPLETED` | `FAILED` (capturing clean error messages without crashing the server).

## Edge cases and security
- Validate `route_id` and `intervention_stop_id` against DB rows BEFORE enqueuing a job (`422`/`404` `ErrorEnvelope`, never spawning SUMO — `BR-007`).
- Guard SSE client disconnect cleanly (`await request.is_disconnected()` + `finally` unsubscribe) so dropped Android connections never leak queues or memory.
- Ensure `GET /experiments/compare` is registered BEFORE `GET /experiments/{id}` in FastAPI routing so `"compare"` is never matched as an experiment ID.
- Serialize SQLite writes carefully between FastAPI threads and the background SUMO executor (fresh SQLAlchemy session per worker job, WAL mode + `busy_timeout=5000`).
